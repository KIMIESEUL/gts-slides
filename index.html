AOI GUI 개선

기획 배경 _ 기본 사용성 부족으로 인한 작업 효율 저하

기본 조작 기능의 부재

Undo/Redo 등 사용자가 기본적으로 기대하는 기능 미지원. 잘못된 설정을 되돌리기 어려움

기능 부재

반복 작업과 시행착오

작은 실수에도 설정을 처음부터 다시 수정. 작업 흐름이 끊기고 불필요한 시간 소모

효율 저하

기본 기대 수준 미충족

기능의 복잡성보다 기본 편의 기능 부족이 더 큰 불편으로 체감. 숙련도와 무관하게 반복 불편

UX 기대치 Gap

기본 기능의 부재가 작업의 불편과 비효율로 직결되고 있다.

"기본 조작 경험을 어떻게 보완할 것인가?"

1. Apply 버튼 개선

AS-IS

① 수정한 내용이 저장되지 않음
검사 조건을 수정한 후 다른 탭으로 이동하면 수정 내용이 저장되지 않고 사라짐

② 탭 이동만으로 작업 내용 유실
사용자가 다른 작업을 위해 탭을 전환하면 이전에 수정한 내용이 초기화됨

③ 수정 내용 재작업 발생
작업 내용이 사라지면서 같은 설정을 다시 수정해야 하는 불필요한 재작업 발생

Missing 선택 ▶ 값 수정 ▶ Apply 안 누름
▶ Pad Overhang 전환 ▶ Missing 수정내용 유실!

TO-BE

① 변경 사항 자동 저장
탭 전환 시 수정 내용을 자동 저장하여 데이터 유실 원천 차단

② 미저장 상태 확인 다이얼로그
미저장 상태에서 탭 전환 시 사용자에게 저장 여부를 확인하는 다이얼로그 제공

2. Undo / Redo 기능 추가

AS-IS

① Undo 기능 부재
편집 작업에 대한 실행 취소(Undo) 기능이 존재하지 않는 구조

② 오조작 시 복구 불가
복구 경로가 없어 전체 설정을 처음부터 재수행해야 하는 비효율 발생

TO-BE

① Ctrl+Z / Ctrl+Y 단축키 지원
모든 편집 작업의 실행 취소 및 재실행을 단축키로 즉시 수행

② 오조작 복구 비용 제로화
작업 흐름의 연속성을 확보하고 재수행 비용 완전 제거

3. Result 화면 개선

AS-IS

① Good Result 필터 적용 시 Viewer 결과 미표시
Good Result 필터 활성화 시 정상(GOOD) 결과가 3D Viewer에 표시되지 않아 결과 확인이 어려움

② 정상 결과 확인 과정 불편
정상 결과를 확인하기 위해 필터를 해제해야 하는 불필요한 과정 발생

TO-BE

① 필터와 Viewer 표시 영역 분리
Good Result 필터는 결과 리스트에만 적용하고, 3D Viewer에는 검사 결과를 계속 표시

② 필터 적용 상태에서도 Viewer 결과 확인
필터를 해제하지 않고도 3D Viewer에서 정상 결과의 위치와 검사 상태를 확인

4. Image Plane 기반 Tolerance 설정 개선

AS-IS

① 인지 부하 발생
Image Plane Popup에서 Gray Value를 기억한 후, Main 화면에서 다시 수동으로 입력해야 함

TO-BE

① 워크플로우 통합
Image Plane Popup을 띄운 상태에서 Image Plane과 Gray Value를 확인하면서 Tolerance 값을 바로 설정할 수 있도록 개선

② 컨텍스트 전환 제거
한 화면에서 완결되는 설정 경험 제공으로 인지 부하 해소

5. Pad Overhang Tolerance 설정 시 Percent 계산

AS-IS

① 수동 환산 필요
Tolerance를 %로 설정할 때 실제 Length/Width 값을 사용자가 직접 환산해야 하는 구조

② 계산 오류 리스크
수동 계산 과정에서 오류 발생 가능성과 불필요한 인지 부하 유발

TO-BE

① 실시간 환산 표시
% 입력 시 해당하는 실제 Length/Width 값을 실시간으로 자동 환산 표시

② 설정 정확도 향상
사용자의 수동 계산을 제거하여 오류 리스크 차단 및 정확도 확보

6. AOI-Addon Add Component : Package 생성 방향 가이드 부족

AS-IS

① 생성 방향 가이드 부재
Package 생성 시 Lead 방향에 대한 시각적 가이드가 없는 구조

② 잘못된 방향으로 생성
올바른 생성 방향을 직관적으로 판단할 수 없어 오류 빈발

③ 다량의 재작업 발생
Package 재생성 및 재작업으로 인한 비용 증가

TO-BE

① 시각적 생성 가이드 제공
Lead 방향 기반의 올바른 생성 방향을 시각적으로 안내

② 생성 전 방향 Validation
생성 전 방향 검증을 통해 오류를 사전 차단하고 재작업 비용 최소화

7. AOI-Addon Add Component : Component 리스트 개선

AS-IS

① 리스트 직접 수정 불가
Component List에서 항목 값의 직접 수정이 불가한 구조

② Rotation 수정 비효율
Rotation 변경 시 Viewer에서 패키지를 수동 회전시키며 각도를 조정해야 하는 워크플로우

TO-BE

① 인라인 수정 지원
Component List 내에서 Component Name, Rotation 값을 직접 수정 가능

② 단일 화면 편집 완결
Viewer 전환 없이 리스트 단일 화면에서 편집을 완결하여 작업 효율 향상

8. AOI-Addon Add Component : Component 선택 및 배치 UX 개선

AS-IS

① 선택 Component 식별 어려움
Viewer에서 선택된 Component의 시각적 Highlight가 부재하여 위치 파악에 불필요한 시간 소요

② Copy & Paste 동작의 비직관성
Ctrl+V 실행 시 마우스 커서 위치가 아닌 복사 원본 주변에 생성되어 추가 탐색 및 이동 필요

③ 불필요한 반복 작업
복사 → 붙여넣기 → 위치 찾기 → 이동의 비효율적 워크플로우로 작업 효율 저하

TO-BE

① 선택 Component Highlight
선택 대상을 시각적으로 명확히 표시하여 즉시 인지 가능

② Mouse Cursor 기반 Paste
Ctrl+V 실행 시 현재 커서 위치에 즉시 배치하여 탐색 단계 제거

기획 아이템 4

AOI PRESETTING GUIDE 구축

기획 배경 _ 3D 복원 작업의 어려움

파라미터의 높은 복잡성

3D 복원 관련 파라미터가 30개 이상이며, 각 파라미터의 역할·상호작용·부작용을 현장 엔지니어가 파악하기 어려움

파라미터 이해 부족

증상–해결 연결의 어려움

3D 무너짐, 노이즈 등 증상이 발생해도 어떤 파라미터를 어떻게 조정해야 하는지 판단 기준이 없음

트러블슈팅 가이드 부재

3D 복원 난이도 증가

이형 부품 증가, 부품 간 간격 축소, 높이 편차 심화 등으로 3D 복원이 어려운 상황이 빈번하게 발생

현장 대응 한계

많은 파라미터를 직접 이해하고 조정하지 않아도, 사용자가 안정적으로 3D를 복원할 수 있도록 지원한다.

"수많은 파라미터 중 무엇을 어떻게 조정해야 하는지 몰라도,
사용자가 안정적으로 3D를 복원할 수 있도록 어떻게 지원할 것인가?"

증상 선택 → 추천 조합 → 적용 → 안정적인 3D 복원
